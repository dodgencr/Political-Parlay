# Reviewing the dashboard

Live dashboard: https://florida-influence-ledger.dodgencr.chatgpt.site

The dashboard is invite-only. Sign in with the email address that was invited. The repository is private and requires a separate GitHub collaborator invitation.

## Give feedback

Open this repository's **Issues** tab, choose **New issue**, and select **Dashboard feedback**. Include the member, tab, what you expected and what you saw. For a data discrepancy, include the original public filing URL.

Useful checks:
- Search for a member and switch between House and Senate.
- Compare one campaign total with its FEC source and reporting date.
- Open a lobbyist record and compare contributor, actual payee, honoree and amount with the original filing.
- Check the financial and travel document links.
- Try the layout on a phone.

Missing matches and partial source searches are not evidence of an absence of financial relationships. Please report misleading labels or uncertainty that needs to be clearer.

GitHub stores the source and feedback; it does not host this running application. This app uses server routes and a D1 database, so uploading it to GitHub Pages alone will not run live synchronization.
